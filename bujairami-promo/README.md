# Bujairami × Fralora – promo video

`bujairami-x-fralora.mp4`: 1080×1920 (Reels/TikTok/Stories), 21 s, Hebrew copy.

Scenes: BUJAIRAMI × FRALORA opening → "לראשונה בארץ" → Executor / Psycho / Too Damn Good / Hectic → collection lineup → call to action.

Re-render: `npx hyperframes render -o renders/out.mp4` in this folder.
The FRALORA wordmark is typeset text (no logo file was available). To use the real logo,
add it to `img/` and swap the `#s1-fralora` and `#s5-fralora` elements in `index.html` for an `<img>`.
